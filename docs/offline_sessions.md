# 离线缓存与登录续期

Android、iOS 和 Web 将网络错误与认证失败分开处理。请求超时显示 `Timeout`。断网、超时和服务器临时故障保留账户与续期凭证。只有续期接口明确返回 401，或用户主动退出，客户端才清除登录状态。

业务接口返回 401 时，客户端先续期，再用同一个操作编号重试一次。这样可以处理已过期的访问凭证。403、业务校验失败和服务器错误不会被当成退出登录的理由。

## 缓存

后台仍拥有全部业务数据。移动端按服务器和账户隔离只读缓存，保存已读取的收据、照片、商品目录、配置和报表。Web 按当前网站和账户保存已读取的 JSON 数据。客户端只缓存可重复读取的结果，不用缓存模拟写入成功。

移动端启动先恢复设备保存的账户信息，并立即显示已缓存的收据总览。登录续期在后台运行。无缓存的页面仍需联网加载。超时后，已有列表继续显示。收据总览在离线期间持续尝试连接，恢复后重新读取后台数据并重试未完成的照片提交。

缓存只在网络错误或超时时作为读取结果使用。服务器明确拒绝权限或校验时，不返回缓存来掩盖错误。成功写入后，客户端清除 JSON 读取缓存，避免下次离线显示已经修改或删除的旧列表。

编辑内容继续留在客户端。保存草稿和录入仍由用户明确触发。请求失败保留编辑内容。未完成的照片保留在原有上传队列中，不删除照片或显示为已经录入。

## 续期响应丢失

新版客户端给 `POST /api/auth/refresh` 传递随机 UUID `request_key`。移动端将编号放在安全凭证存储中。Web 保留该编号，并通过浏览器锁串行处理同一网站的续期。超时和断网后，下次续期重复使用该编号。成功接受新凭证后，客户端删除编号。

后台通过独立用途的 HS256 签名确定本次轮换的续期凭证。数据库只保存其哈希，不保存明文响应。即使客户端丢失响应或服务重启，旧凭证与相同编号仍可恢复当前轮换结果。

错误编号不能恢复旧凭证。下一次轮换、过期、退出、删除用户或密码重置会使该恢复路径失效。后台仍检查数据库中的有效会话与用户状态。没有传入编号的旧客户端继续使用原有单次轮换行为。

本次修改没有更改数据库结构，不需要迁移或重置 NAS 数据。
