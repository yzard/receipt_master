## 实现中的明确取舍

1. **识别供应商**：首发实现 Chat Completions 图片 + JSON Schema 协议适配器；地址、模型、个人密钥由用户配置。代码不会偷偷调用环境中的其他凭据。
2. **相机**：第一版调用系统相机逐段拍摄，返回后查看已有段落和排序；没有连续全景或实时重叠取景叠层。
3. **图像质量**：使用图像细节启发式提示，不宣称准确检测所有模糊、反光或缺边；最终由用户对照照片确认。
4. **费用**：用户提供 USD/百万 token 的输入输出价格，有用量才估算，每请求向上取整至美分。其他币种预算不自动换汇；费用未知或达到预算均不会禁止识别。
5. **备份大小**：第一版压缩包在后台内存中构建和校验。大量多年照片的峰值内存和耗时尚未在低内存真机验证；照片压缩、后台处理和错误保留不能替代容量测试。
6. **版本迁移**：当前只有 schema v1，无已发布历史版本需要迁移；拒绝较新/不匹配结构，不通过删库“升级”。首版发布后更改 schema 必须增加版本和迁移测试。
7. **正式编辑**：明细和金额只在确认提交后更新；照片添加、旋转和排序即时保存，照片操作不改变历史金额。
8. **运行平台**：Android 真机相机、相册权限、分享与恢复仍需实测；iOS 工程及权限、Keychain 配置已准备，Linux 无法替代 Xcode 编译和 Apple 设备测试。

## Android 客户端更新
