# Qwen3.8 Flash Next 可运行性与收据评测

日期：2026-10-25。Flash Next 的实际对比未完成，因为当前机器的主内存不足。本次完成可运行性核对、数据库快照、唯一草稿的失败诊断，以及现有 27B 模型的单张重新测试。未替换生产模型，未写入收据、任务或商品目录。

## Flash Next 的运行限制

新版 NInfer 支持 Flash Next 的文字、图像及原生 MTP 推理。核对版本为 `64d10fbf9f8e6bfc79ab0570b94674c5b9997929`，生产服务仍使用 `9e163eee4b8acec21ab0ac765107b6a3f287b217`。

新版引擎将 Main experts 的完整来源保留在 registered Host memory，同时使用 GPU 缓存及 CPU/GPU 混合执行。仅这部分主内存就需要 67,947,921,408 bytes，即 63.28 GiB，另需系统与运行内存。本机物理内存为 60.24 GiB，因此即使释放其他应用也无法满足此要求。减小上下文或 GPU 缓存不会移除完整 Host backing。

本机 GPU 为 RTX 5090，显存为 32 GB。没有下载约 109.68 GB 的分卷模型，也没有通过尝试超额分配内存来测试。没有候选模型输出，因此不报告 Flash Next 的收据准确率、耗时或胜负。

依据：[固定版本的运行要求](https://github.com/Neroued/ninfer/blob/64d10fbf9f8e6bfc79ab0570b94674c5b9997929/docs/cli.md)、[权重存储与放置](https://github.com/Neroued/ninfer/blob/64d10fbf9f8e6bfc79ab0570b94674c5b9997929/docs/maintainer/qwen4_exp-model.md)、[候选模型文件清单](https://huggingface.co/igorls/Qwen3.8-Flash-Next-mixed-NInfer/tree/ef61b3c856f91e58a58e41a5a6269b6c8648d266)。

## 空明细草稿的原因

草稿为 McDonalds，编号 `b123c3f3-5b55-4499-8e76-eb6626657f28`。

原归档的店铺定位结果为 `box: null`，图像别名匹配为 `selected: null`、`matches: []`。当时没有匹配到店铺参照，商品提取使用通用提示词。现有规则要求店名来自图像别名匹配，不允许直接把票面文字推断出的品牌作为店名。

原任务 `dcc262cb-8d8f-4d18-9392-07ae9fb2e010` 的状态是 `succeeded`，错误说明是 `stale_input`。模型运行记录同样为成功，原归档包含 4 件商品和 1 条税费，总额 21.10 USD。生产草稿仍为空，是因为结果没有通过输入快照合并保护，并非该次模型没有返回商品。

任务提交版本为 2，当前草稿版本为 5，照片 revision 相同。保护逻辑还会比较明细、国家、币种和店铺类别；保留的已完成任务记录没有原始 source 快照，不能确定具体哪个输入字段导致拒绝。换模型不会绕过这项写回保护。

后续修复（2026-10-25）：上述诊断描述修复前的任务。当前 NAS 已移除结果写回的快照一致性保护，明确重新识别会替代旧任务。生产草稿保持原值，等待用户重新识别；这项修复不代表完成 Flash Next 模型测试。

## 现有 27B 模型重新测试

使用当前 NAS 通用提示词、当前结构约束、原图和生产 OCR 配置。已知店名使用保存的 McDonalds 图像别名，本次不测 Logo 匹配。没有向模型发送商品标准答案。

模型以 `finish_reason=stop` 完整返回，JSON Schema 校验通过。照片核对结果如下。

| --- | --- | --- |
| 4 件有价格商品的票面名称及金额 | 4/4 吻合 | 未运行 |
| 税额 | 1.44 USD，吻合 | 未运行 |
| 总额 | 21.10 USD，吻合 | 未运行 |
| 交易时间 | 2026-10-16 18:36:00，吻合 | 未运行 |
| 返回明细数 | 6，其中 1 条无金额附注被单列 | 未运行 |
| 无需人工核对的完整正确结果 | 否 | 未运行 |

具体限制是 `S Bev Surcharge`：照片没有为它单独列出金额，模型将其作为 `other_adjustment`，金额为 null。这条附注不能作为另一笔已定价消费。已知金额合计等于票面总额，但由于存在空金额，不能声称完整明细校验通过。

原归档没有单列该附注，而是把它作为 Coke 的说明。本次重新测试单列了它，表明输出存在变化；两次结果不能混为一次全部正确的测试。

本次输入 15,697 tokens，输出 3,621 tokens，其中思考 2,278 tokens。引擎报告的 prompt 用时为 4.05 秒、生成用时为 18.59 秒。这不是包含冷加载与传输的总耗时；总耗时未保留，不作估算。
